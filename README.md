# ⏰ HR System — تطبيق الحضور والأوفرتايم

تطبيق موبايل (PWA) بيتثبّت على الموبايل بأيقونة ويفتح ملء الشاشة. البيانات كلها بتفضل في **Google Sheet بتاعك**.

- 📲 **بيتثبّت زي أي تطبيق:** أيقونة على الشاشة الرئيسية، ومن غير شريط المتصفح.
- 📴 **بيفتح من غير نت:** بيعرض آخر بيانات اتسجّلت، والحضور والانصراف بيتسجّلوا بوقتهم الحقيقي ويتبعتوا لوحدهم أول ما النت يرجع.
- ⚡ **بيفتح على طول:** الشاشة بتظهر فورًا من البيانات المحفوظة، وبعدين بتتحدّث من الشيت.
- 🔐 **آمن:** كل طلب لازم يكون معاه "مفتاح ربط" عشوائي (256 بت). من غير المفتاح محدش يقدر يوصل لبياناتك.
- ✨ **بيتحدّث لوحده:** أي نسخة جديدة على GitHub بتوصلك برسالة "فيه تحديث جديد".
- 👆 **تسجيل بلمسة واحدة:** زرار "سجّل" العائم (ظاهر في كل التابات) بيسجّل حضور أو انصراف بالوقت الحالي على طول، ومعاه "تراجع" لمدة 9 ثواني. ضغطة طويلة عليه = تسجيل مع صورة البصمة.
- 🗂️ **اختصار من الأيقونة:** دوسة مطوّلة على أيقونة التطبيق ← "سجّل" = بيسجّل على طول أول ما يفتح (حتى من غير نت).

```
┌──────────────────────┐   HTTPS + مفتاح الربط   ┌──────────────────────┐
│  تطبيق الموبايل (PWA) │ ─────────────────────▶ │  Apps Script (API)    │ ──▶ Google Sheet
│  GitHub Pages         │ ◀───────────────────── │  doPost → نفس الدوال  │
└──────────────────────┘          JSON           └──────────────────────┘
```

## التركيب (مرة واحدة)

### 1) Apps Script — حدّث الكود
في محرر Apps Script بتاع الشيت:
- **ملفات جديدة:** `Api` (Script) و `MobileSetup` (HTML).
- **استبدل:** `App` و `WebApp`.
- باقي الملفات اتغيّر فيها رقم النسخة في التعليقات بس — تقدر تستبدلها أو تسيبها.

### 2) Apps Script — انشر الـ API
**Deploy ← Manage deployments ← ✏️ (النشر الحالي)**:
- Execute as: **Me**
- Who has access: **Anyone** ⚠️ (ده لازم، عشان التطبيق يقدر يكلّم الشيت. الحماية بمفتاح الربط)
- Version: **New version** ← **Deploy**

> لينك الـ Web App القديم بقى مقفول (🔒). بيفتح بس لو إنت مسجّل دخول بحساب صاحب الشيت، أو باللينك اللي فيه `?k=مفتاح_الربط`.

### 3) GitHub — ارفع التطبيق
1. [github.com/new](https://github.com/new) ← اسم الـ repo: `hr-system` ← **Public** ← Create.
2. **uploading an existing file** ← اسحب **كل** الملفات والفولدرات اللي هنا ← **Commit changes**.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save**.
4. بعد دقيقة هيبقى التطبيق على: `https://اسمك.github.io/hr-system/`

> الـ repo لازم يبقى Public عشان GitHub Pages المجاني. الكود مفيهوش أي بيانات ولا مفاتيح: مفتاح الربط متخزّن في Script Properties جوه Apps Script بس.

### 4) اربط الموبايل
1. افتح الشيت ← **⚙️ HR System ← 📱 ربط تطبيق الموبايل** ← الصق لينك GitHub Pages.
2. اضغط **📧 ابعت لينك الربط على إيميلي**.
3. افتح الإيميل **من الموبايل** واضغط **📲 ربط التطبيق**. التطبيق هيفتح ويتربط لوحده.
4. ثبّته:
   - **أندرويد (Chrome):** ⋮ ← **Install app / تثبيت التطبيق** (أو من الضبط ← 📲 ثبّت التطبيق)
   - **آيفون (Safari):** زرار المشاركة ⬆️ ← **Add to Home Screen**

## الأمان
- **المفتاح:** عشوائي 64 حرف، متخزّن في Script Properties، وبيتقارن بوقت ثابت.
- **الدوال المسموحة:** التطبيق يقدر ينادي بس على الدوال اللي الواجهة بتستخدمها (`apiMap_` في `Api.gs`). أي دالة داخلية مرفوضة.
- **المفتاح على الموبايل:** متخزّن على الموبايل نفسه بس، ولينك الربط بيتمسح من شريط العنوان أول ما يفتح.
- **لو موبايلك ضاع أو المفتاح اتسرّب:** من الشيت ← 📱 ربط تطبيق الموبايل ← **🔑 مفتاح جديد**. أي موبايل مربوط بالمفتاح القديم بيتفصل فورًا.
- **الصور:** خاصة في Drive، وبتوصل للتطبيق عن طريق الـ API.

## التحديث بعد كده
- **تعديل في الكود (`.gs`):** عدّل في Apps Script ← Deploy ← Manage deployments ← ✏️ ← **New version**.
- **تعديل في الواجهة (`.html`):** عدّل في `apps-script/HTML` (وفي Apps Script)، وبعدين:
  ```
  python3 tools/build.py
  ```
  وارفع `index.html` الجديد على GitHub. الموبايل هيقولك "✨ فيه تحديث جديد".
- **لو غيّرت `sw.js` أو الأيقونات:** زوّد رقم `VERSION` في `sw.js`.
